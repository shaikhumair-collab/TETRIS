# 🎮 Tetris Game in C

A classic Tetris game developed in C as a Programming Fundamentals project.

## 📌 Features

- Classic Tetris gameplay
- Different Tetris blocks
- Block movement and rotation
- Line clearing
- Score tracking
- High-score system
- Game-over detection

## 🎮 Controls

| Key | Action |
|---|---|
| A | Move Left |
| D | Move Right |
| W | Rotate |
| S | Move Down |
| Q | Quit |

## 🛠️ Technologies Used

- C Programming
- GCC Compiler
- Console/Terminal

## ▶️ How to Run

Compile the source code:

```bash
gcc project.c -o project
